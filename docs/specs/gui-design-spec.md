# GUI 設計規格

## 目標

提供繁體中文 PySide6 桌面介面，讓使用者可以載入賽道與團子設定、跑單場模擬、執行大量勝率模擬，後續再擴充視覺化賽道編輯器。

## MVP 畫面

- 標題：`DangoSimulator 小團快跑模擬器`
- 載入內建 `data/default_race.json`
- 顯示參賽團子數量與可勾選團子卡片
- 控制：開始、下一步、自動播放 checkbox、暫停、重置
- 顯示目前輪數、行動團子與骰子結果
- 賽道棋子以團子名稱第一個字作為棋子文字
- 同格堆疊時，上方團子的垂直位置與圖層都高於下方團子
- 目前行動團子以外框高亮，不破壞堆疊上下關係
- 即時名次以表格顯示排名、團子名稱、對應棋子圖示、目前格數與狀態
- 本輪行動以表格顯示行動順序、團子名稱、對應棋子圖示、本輪骰子與行動狀態
- 按鈕：執行多輪模擬、停止模擬
- 批次模擬場數輸入：1 到 99999999，寬度可容納 `9999,9999` 等級輸入
- 結果區：表格顯示勝場、勝率、平均名次與綜合分數
- 事件紀錄位於最右側獨立欄；每回合行動順序與比賽結束訊息不縮排，其他事件縮排顯示
- 自動儲存並於下次啟動恢復：參賽團子、布大王模式、速度、單場自動播放、多輪場數、Seed 模式、Seed 輸入、CPU worker 與排序模式

## 後續擴充

- JSON 設定編輯器。
- 裝置與能力表單。
- pyqtgraph 勝率與平均名次圖表。
- 錯誤面板顯示 JSON 驗證失敗原因。

## 邊界

GUI 不直接修改 core 狀態內部欄位。
所有模擬都應建立 `RaceSimulator` 或呼叫 CLI 共用的 `simulate_many`。
