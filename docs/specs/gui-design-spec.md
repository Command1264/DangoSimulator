# GUI 設計規格

## 目標

提供繁體中文 PySide6 桌面介面，讓使用者可以載入賽道與團子設定、跑單場模擬、執行大量勝率模擬，後續再擴充視覺化賽道編輯器。

## MVP 畫面

- 視窗預設最大化啟動
- 主畫面使用上方 tab 切換單輪模擬、多輪模擬與設定工作區
- 標題 `DangoSimulator 小團快跑模擬器` 顯示在中央賽道區上方置中，視窗標題列保留同名 title
- 單輪模擬工作區的左右資訊欄固定等寬，中央賽道區吃掉剩餘寬度，讓地圖在最大化與視窗模式下維持水平置中
- 載入內建 `data/default_race.json`
- 顯示參賽團子數量與可勾選團子卡片
- 控制：開始、下一步、自動播放 checkbox、暫停、重置
- 顯示目前輪數、行動團子與骰子結果
- 賽道棋子以團子名稱第一個字作為棋子文字
- 同格堆疊時，上方團子的垂直位置與圖層都高於下方團子
- 目前行動團子以外框高亮，不破壞堆疊上下關係
- 即時名次以表格顯示排名、團子名稱、對應棋子圖示、目前格數與狀態
- 本輪行動以表格顯示行動順序、團子名稱、對應棋子圖示、本輪骰子與行動狀態
- 即時名次與本輪行動表格不自動換行，團子名稱欄需能單行顯示約 6 個繁體中文字
- 即時名次欄位對齊：名次置中、團子靠左、格數置中、狀態置中
- 本輪行動欄位對齊：順序置中、團子靠左、骰子置中、狀態置中
- 按鈕：執行多輪模擬、停止模擬
- 單輪模擬與多輪模擬可同時執行；任一流程執行時只鎖住參賽團子與 Seed 設定，兩個流程的開始/停止控制不互鎖
- 批次模擬場數輸入：1 到 99999999，寬度可容納 `9999,9999` 等級輸入
- Seed 輸入欄位旁顯示 `固定 Seed：` label；系統隨機 seed 模式下固定 seed 輸入欄位停用但保留使用者輸入，不被實際系統 seed 覆寫
- 結果區：表格顯示勝場、勝率、平均名次與綜合分數，並可直接點 header 排序
- 結果表高度至少保留約 7 列可視空間，方便一次檢視 6 到 7 位參賽者
- 結果表欄位對齊：排名置中、團子靠左、勝場/勝率/平均名次/綜合分數靠右
- 結果表預設依綜合分數遞減排序；排名欄不可排序，只顯示目前排序下的視覺排名
- 事件紀錄位於單輪模擬工作區左側；每回合行動順序與比賽結束訊息不縮排，其他事件縮排顯示
- 事件紀錄更新時，若原本沒有縱向卷軸或卷軸已在底部，更新後自動捲到最新事件；若使用者正在回看舊事件，則不強制改變卷軸位置
- 自動儲存並於下次啟動恢復：參賽團子、布大王模式、速度、單場自動播放、多輪場數、Seed 模式、Seed 輸入與 CPU worker

## 後續擴充

- JSON 設定編輯器。
- 裝置與能力表單。
- pyqtgraph 勝率與平均名次圖表。
- 錯誤面板顯示 JSON 驗證失敗原因。

## 邊界

GUI 不直接修改 core 狀態內部欄位。
所有模擬都應建立 `RaceSimulator` 或呼叫 CLI 共用的 `simulate_many`。
