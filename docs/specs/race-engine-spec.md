# 小團快跑規則引擎規格

## 目標

建立純 Python 模擬核心，讓 GUI、CLI 與測試共用同一套規則。

## MVP 規則

- 一般團子順時針移動。
- 布大王逆時針移動。
- 每回合開始時，先將可行動團子洗牌形成行動順序；同一回合內每顆可行動團子最多行動一次。
- 一般團子骰 1 到 3。
- 布大王骰 1 到 6。
- 落到同格時，後到者堆疊在上方。
- 底部團子移動時，帶動上方整個堆疊。
- 任一一般參賽團子抵達終點時，比賽立即結束。
- 完賽名次與即時名次都依最靠近終點到最遠排序；若位於同一格，依堆疊由上至下排序。
- 裝置只在移動終點落格時觸發。
- 推進裝置前進 1 格。
- 阻遏裝置後退 1 格。
- 時空裂隙重排落點堆疊。
- 布大王對推進/阻遏裝置效果反轉。
- 布大王第 3 回合才加入行動順序。
- 布大王永遠位於堆疊底部，且行動時不帶走一般團子。
- 第 3 回合後每輪結束時，若布大王與最後一名一般團子分開，布大王傳送回終點。

## Builtin 團子能力

目前支援的 JSON builtin ability id：

- `sigurd_sun_help`：西格莉卡每輪標記前方至多兩個團子，該回合少走 1 格，最低仍為 1 格。
- `floro_bottom_bonus`：弗洛洛在堆疊底部時額外前進 3 格。
- `linne_colorful`：琳奈 20% 不移動、60% 雙倍步數、20% 正常移動。
- `shorekeeper_future`：守岸人只會擲出 2 或 3。
- `aemiss_ghost`：愛彌斯每場一次，越過賽程中點後傳送到前方最近一般團子頂端。
- `snow_bird`：緋雪遇到布大王後，後續每次移動額外前進 1 格。
- `lu_device_master`：陸赫斯觸發推進時額外前進 3 格，觸發阻遏時額外後退 1 格。
- `daphne_same_roll_bonus`：達妮婭若骰出與上次相同點數，額外前進 2 格。
- `kat_activate_late_surge` / `kat_late_surge_bonus`：卡提希婭每場最多一次在最後一名時進入追趕狀態，後續 60% 額外前進 2 格。
- `phoebe_bonus` / `chisaki_bonus`：菲比、千咲 50% 額外前進 1 格。
- `colletta_double_authority`：珂萊塔 28% 以雙倍點數移動。

## 假設

部分官方細節仍需透過後續資料校正，因此所有裝置與能力效果都要保留 JSON 可配置能力。
