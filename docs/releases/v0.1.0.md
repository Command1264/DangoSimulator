# DangoSimulator v0.1.0 Release Notes

## Summary

v0.1.0 is the first release candidate for the PySide6 desktop simulator and shared headless simulation core.

## Highlights

- Adds the core race engine for movement, device resolution, turn order, stacking, boss behavior, midpoint triggers, and built-in dango abilities.
- Adds a Traditional Chinese GUI for participant setup, single-race playback, event logs, live rankings, current-round actions, and batch simulations.
- Adds fixed seed and system random seed modes; system random seed displays the actual run seed without overwriting the fixed Seed input field.
- Adds multi-run batch simulation with progress, ETA, result ranking, CPU worker selection, and CSV/JSON-capable CLI support.
- Adds Windows PyInstaller packaging through `scripts/build-exe.ps1` and `DangoSimulator.spec`.

## Built-In Data

- Includes the default race track, midpoint marker, devices, boss dango, and A/B/C group dango data from `data/default_race.json`.
- Default midpoint is position 25 and coexists with the block device on that position.

## Verification

- Full pytest suite.
- Python compile check for `dangosim`.
- GUI smoke test.
- PyInstaller Windows EXE build.

## Known Limits

- Manual QA still needs to be run before merging the release branch to `main`.
- Visual assets are abstract colored pieces rather than official art assets.
