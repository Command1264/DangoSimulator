# DangoSimulator v0.2.0 Release Notes

## Summary

v0.2.0 updates the race engine to match the latest confirmed dango ability timing and boss movement rules, with regression tests and documentation aligned to the current default race data.

## Highlights

- Fixes 布大王 carrying behavior so passed or landed regular dangos are picked up and carried in the correct stack order.
- Fixes 布大王 return-to-finish logic so a regular dango on the same position prevents returning.
- Updates 奧古斯塔 so the forced last-action round skips the top-of-stack check and allows actual movement.
- Updates 愛彌斯 and 尤諾 to unlock after crossing midpoint, then consume their once-per-race ability only on successful activation.
- Updates 尤諾 to pull all regular dangos to her position when she is neither first nor last, preserving rank-based stack order.
- Adds `round_end` ability timing and moves 長離 and 今汐 checks to round end.
- Updates the default race midpoint marker to position 16.

## Verification

- Full pytest suite.
- Python compile check for `dangosim`.
- GUI smoke test.
- PyInstaller Windows EXE build.

## Known Limits

- Visual assets remain abstract colored pieces rather than official art assets.
