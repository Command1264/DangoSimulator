# DangoSimulator v0.3.0 Release Notes

## Summary

v0.3.0 focuses on the GUI workflow: single-race, batch simulation, and shared settings are now split into clearer workspaces, while race setup and seed settings are centralized so general users can stay inside the GUI.

## Highlights

- Splits the main GUI into top workspace tabs for single-race simulation, batch simulation, and settings.
- Moves participant setup and shared seed settings into the settings workspace.
- Lets single-race and batch simulations run independently while locking shared participant and seed settings during active runs.
- Adds sortable batch result headers with weighted score as the default sort.
- Improves single-race layout so the map stays centered and status tables have wider name columns.
- Refines participant setup dialog layout, including wrapping selection summaries and consistent skill description sizing.
- Keeps system-random seed runs from overwriting the fixed Seed input value.

## Verification

- Full pytest suite.
- Python compile check for `dangosim`.
- GUI smoke test.
- GUI layout probe.
- PyInstaller Windows EXE build.

## Known Limits

- Status table selection styling uses the platform/default table behavior after the custom selection style attempts were reverted.
- Visual assets remain abstract colored pieces rather than official art assets.
