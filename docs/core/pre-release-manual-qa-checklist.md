# Pre-release Manual QA Checklist

## GUI

- [ ] 可啟動 PySide6 GUI。
- [ ] 可載入預設小組賽資料。
- [ ] 可在左側卡片勾選一般團子參賽。
- [ ] 團子卡片不顯示 `A組`、`WIP` 等分組標籤。
- [ ] WIP 團子卡片會顯示但不預設參賽。
- [ ] 可將布大王切換為干擾者或參賽者。
- [ ] 布大王在第 1、2 回合不行動，第 3 回合才加入行動順序。
- [ ] 整輪結束時，若布大王前進方向到終點前仍有一般團子，布大王不會回終點。
- [ ] 整輪結束時，若布大王前進方向到終點前已無一般團子，布大王會回終點重新開始。
- [ ] 可執行單場模擬並看到事件紀錄。
- [ ] 事件紀錄會顯示每回合行動順序。
- [ ] 單場模擬會顯示目前第幾輪。
- [ ] 任一一般參賽團子抵達終點後，比賽立即結束並產生所有參賽團子名次。
- [ ] 即時名次以最接近終點到最遠排序，同格時依堆疊由上至下排序。
- [ ] 即時名次顯示團子名稱與對應棋子圖示，棋子文字為團子名稱第一個字。
- [ ] 中央賽道同格堆疊時，上方團子的棋子與文字都高於下方團子。
- [ ] 中央賽道裝置不會蓋住團子；目前行動團子會顯示高亮外框。
- [ ] 初始狀態只有開始、參賽團子設定、速度、多輪模擬執行、場數、Seed、排序可操作。
- [ ] 單輪模擬開始後，下一步、自動播放、暫停、重置才可操作，開始與參賽團子設定不可操作。
- [ ] 點「下一步」後中央賽道、骰子、名次與事件紀錄會更新。
- [ ] 自動播放可暫停與重置。
- [ ] 重置後會回到初始控制狀態。
- [ ] 可執行批次模擬並看到勝率摘要。
- [ ] 多輪模擬場數欄位可輸入到 99999999，欄位寬度可容納 `9999,9999` 等級文字。
- [ ] 多輪模擬執行前會依場數試跑樣本場數並顯示預估時間。
- [ ] 多輪模擬執行中會顯示完成場數、總場數與 ETA。
- [ ] 多輪模擬執行中場數、Seed 模式、Seed 輸入與執行按鈕不可操作，停止模擬可操作。
- [ ] 按下停止模擬後，多輪模擬控制會回到初始狀態。
- [ ] 固定 seed 連跑兩次同設定會得到相同批次結果。
- [ ] 系統隨機 seed 會顯示並回填本次實際使用 seed。
- [ ] 關閉並重新啟動 GUI 後，參賽團子、布大王模式、速度、多輪場數、Seed 模式、Seed 輸入與排序模式會恢復。
- [ ] 使用者設定檔損壞時 GUI 仍可啟動，並回到安全預設值。
- [ ] 批次結果表顯示勝場、勝率、平均名次與綜合分數。
- [ ] JSON 錯誤會顯示可理解訊息。

## CLI

- [ ] `dangosim simulate` 可讀取預設資料。
- [ ] 預設資料可套用團子 builtin 技能並完成批次模擬。
- [ ] 固定 seed 的輸出可重現。
- [ ] 系統隨機 seed 的 JSON/CSV 輸出包含本次實際使用 seed。
- [ ] 可輸出 JSON。
- [ ] 可輸出 CSV。

## Packaging

- [ ] Windows EXE 可啟動。
- [ ] EXE 可找到內建 `data/`。
- [ ] EXE 可完成一次 headless 模擬。
