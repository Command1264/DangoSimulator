# Pre-release Manual QA Checklist

## GUI

- [ ] 可啟動 PySide6 GUI。
- [ ] 可載入預設小組賽資料。
- [ ] 可在左側卡片勾選一般團子參賽。
- [ ] 團子卡片不顯示 `A組`、`WIP` 等分組標籤。
- [ ] WIP 團子卡片會顯示但不預設參賽。
- [ ] 可將布大王切換為干擾者或參賽者。
- [ ] 布大王在第 1、2 回合不行動，第 3 回合才加入行動順序。
- [ ] 整輪結束時，若布大王前進方向到終點前仍有一般團子，布大王不會回終點。
- [ ] 整輪結束時，若布大王前進方向到終點前已無一般團子，布大王會回終點重新開始。
- [ ] 可執行單場模擬並看到事件紀錄。
- [ ] 事件紀錄會顯示每回合行動順序。
- [ ] 事件紀錄中「第 N 回合行動順序」與「比賽結束」不縮排，其他事件縮排。
- [ ] 單場模擬會顯示目前第幾輪。
- [ ] 任一一般參賽團子抵達終點後，比賽立即結束並產生所有參賽團子名次。
- [ ] 即時名次以最接近終點到最遠排序，同格時依堆疊由上至下排序。
- [ ] 即時名次顯示團子名稱與對應棋子圖示，棋子文字為團子名稱第一個字。
- [ ] 中央賽道同格堆疊時，上方團子的棋子與文字都高於下方團子。
- [ ] 中央賽道裝置不會蓋住團子；目前行動團子會顯示高亮外框。
- [ ] 初始狀態只有開始、參賽團子設定、速度、自動播放 checkbox、多輪模擬執行、場數、Seed、CPU worker、排序可操作。
- [ ] 單輪模擬開始後，下一步、自動播放 checkbox、暫停、重置才可操作，開始與參賽團子設定不可操作。
- [ ] 點「下一步」後中央賽道、骰子、名次與事件紀錄會更新。
- [ ] 自動播放 checkbox 勾選後會自動播放，按暫停會取消勾選，重置會停止播放。
- [ ] 開始前可勾選自動播放 checkbox，按下開始後會直接自動播放。
- [ ] 重置後會回到初始控制狀態。
- [ ] 可執行批次模擬並看到勝率摘要。
- [ ] 多輪模擬場數欄位可輸入到 99999999，欄位寬度可容納 `99,999,999` 等級文字。
- [ ] 多輪模擬場數欄位每次變更都會即時補上千分位逗號，不需等到失焦。
- [ ] 多輪模擬場數欄位在逗號旁按 Backspace/Delete 時，會刪除逗號左側/右側的數字，且游標不會多跳一格。
- [ ] Seed 模式選擇系統隨機 seed 時，Seed 輸入欄位不可編輯；切回固定 seed 後可編輯。
- [ ] CPU worker 選項包含自動、全力與 1 到目前 CPU core 數。
- [ ] CPU worker 自動模式使用約 2/3 CPU core，全力模式使用目前 CPU core 數。
- [ ] 載入較高核心電腦儲存的過大 CPU worker 數時，GUI 會回退到自動。
- [ ] 多輪模擬執行前會依場數試跑樣本場數，並以 Yes/No 對話框顯示正式 worker 數與預估時間，對話框內整數數字會使用千分位逗號。
- [ ] 多輪模擬預估對話框按 No 不會開始正式模擬；按 Yes 才會開始。
- [ ] 多輪模擬執行中會顯示完成場數、總場數與 ETA。
- [ ] 多輪模擬執行中場數、Seed 模式、Seed 輸入、CPU worker 與執行按鈕不可操作，停止模擬可操作。
- [ ] 按下停止模擬後，多輪模擬控制會回到初始狀態。
- [ ] 固定 seed 連跑兩次同設定會得到相同批次結果。
- [ ] 系統隨機 seed 會顯示並回填本次實際使用 seed。
- [ ] 關閉並重新啟動 GUI 後，參賽團子、布大王模式、速度、單場自動播放、多輪場數、Seed 模式、Seed 輸入、CPU worker 與排序模式會恢復。
- [ ] 使用者設定檔損壞時 GUI 仍可啟動，並回到安全預設值。
- [ ] 批次結果表顯示勝場、勝率、平均名次與綜合分數。
- [ ] JSON 錯誤會顯示可理解訊息。

## CLI

- [ ] `dangosim simulate` 可讀取預設資料。
- [ ] `dangosim simulate --workers auto` 可完成多核心批次模擬。
- [ ] `dangosim simulate --workers full` 可完成多核心批次模擬。
- [ ] 預設資料可套用團子 builtin 技能並完成批次模擬。
- [ ] 固定 seed 的輸出可重現。
- [ ] 同一固定 seed 使用 `--workers 1` 與 `--workers auto` 會產生相同統計結果。
- [ ] 系統隨機 seed 的 JSON/CSV 輸出包含本次實際使用 seed。
- [ ] 可輸出 JSON。
- [ ] 可輸出 CSV。

## Packaging

- [ ] Windows EXE 可啟動。
- [ ] EXE 可找到內建 `data/`。
- [ ] EXE 可完成一次 headless 模擬。
