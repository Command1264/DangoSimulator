# Pre-release Manual QA Checklist

## GUI

- [ ] 可啟動 PySide6 GUI。
- [ ] GUI 啟動時預設最大化。
- [ ] 主畫面上方 tab 可切換「單輪模擬」、「多輪模擬」與「設定」三個工作區。
- [ ] 單輪模擬工作區顯示事件紀錄、賽道、即時名次與本輪行動，且不顯示團子設定入口。
- [ ] 多輪模擬工作區顯示場數、CPU worker、進度/ETA 與結果表，且不顯示 Seed 設定欄位。
- [ ] 設定工作區顯示目前參賽團子、全域 Seed 設定、單輪設定與多輪設定摘要。
- [ ] 應用標題顯示在中央賽道區上方置中，不再佔用整個視窗最上方獨立列。
- [ ] 單輪模擬工作區在最大化與一般視窗模式下，地圖都維持在工作區水平正中；左右資訊欄視覺寬度一致。
- [ ] 可載入預設小組賽資料。
- [ ] 可從設定工作區的「自訂參賽團子」按鈕開啟彈出式參賽設定視窗。
- [ ] 可在彈出視窗中以卡片方式勾選一般團子參賽，且不限制最多 6 顆。
- [ ] 參賽設定視窗預設每列顯示 4 張團子卡片，且不出現橫向卷軸。
- [ ] 參賽設定視窗選取大量團子時，已選團子摘要會依視窗寬度換行，不會撐大整個 UI。
- [ ] 團子卡片不顯示 checkbox 方框，只用卡片顏色、邊框與控制項啟用狀態表示是否參賽。
- [ ] 團子卡片左上角以圓形或橢圓形 badge 顯示 group。
- [ ] 團子卡片的頭像與名稱上下排列並置中顯示。
- [ ] 團子卡片技能描述框文字上下左右置中，且同一排卡片的技能描述框高度一致。
- [ ] 團子卡片可顯示 group、初始位置、初始堆疊順序與首回合順序，且初始堆疊與首回合順序並排顯示。
- [ ] 參賽設定視窗中滑鼠停在初始位置、初始堆疊、首回合順序或布大王模式欄位上時，滾輪會捲動整個彈窗，不會改變欄位值。
- [ ] 參賽設定視窗按「取消」不套用變更，按「確認」才更新主畫面摘要與使用者設定。
- [ ] 團子卡片可顯示正式 group，但不顯示 `WIP` 類狀態標籤。
- [ ] 非預設參賽團子的卡片會顯示，但不預設參賽。
- [ ] 可將布大王切換為干擾者或參賽者。
- [ ] 布大王在第 1、2 回合不行動，第 3 回合才加入行動順序。
- [ ] 布大王經過或停在一般團子所在格時，會將該格一般團子背起並繼續移動。
- [ ] 布大王背上已有團子時，新背起的團子會位於布大王與原背上團子之間，且原堆疊順序不變。
- [ ] 布大王同格仍背著一般團子時，回合結束不會傳送回終點。
- [ ] 整輪結束時，若布大王前進方向到終點前仍有一般團子，布大王不會回終點。
- [ ] 整輪結束時，若布大王前進方向到終點前已無一般團子，布大王會回終點重新開始。
- [ ] 可執行單場模擬並看到事件紀錄。
- [ ] 單場模擬進行中切換到其他工作區後再切回，賽道、事件紀錄與控制狀態仍保留。
- [ ] 事件紀錄會顯示每回合行動順序。
- [ ] 事件紀錄使用團子與裝置顯示名稱，不顯示內部 id，例如 `advance`、`block` 或團子 id。
- [ ] 地圖格子 tooltip 使用「推進裝置」、「阻遏裝置」、「時空裂隙」等顯示名稱，不顯示 `advance`、`block`、`time_rift`。
- [ ] 地圖 tooltip 預設顯示於目標右上；右上放不下時依序改用左上、左下、右下，最後才限制在 viewport 內。
- [ ] 棋子 tooltip、目前行動者與即時名次使用團子名稱；缺少名稱時顯示通用 fallback，不顯示團子 id。
- [ ] 事件紀錄中「第 N 回合行動順序」與「比賽結束」不縮排，其他事件縮排。
- [ ] 事件紀錄沒有縱向卷軸或卷軸在最底部時，新增事件後會自動捲到最底部。
- [ ] 使用者正在往上回看事件紀錄時，新增事件不會強制把卷軸拉到最底部。
- [ ] 單場模擬會顯示目前第幾輪。
- [ ] 任一一般參賽團子抵達終點後，比賽立即結束並產生所有參賽團子名次。
- [ ] 奧古斯塔因技能排到下回合最後行動時，該回合開始會略過最上方檢查並實際行動。
- [ ] 尤諾越過中點後，移動完成且非最前/最後時會將所有一般團子拉到自己位置。
- [ ] 愛彌斯越過中點後，若當下沒有前方目標不消耗技能，之後有目標時仍可觸發一次。
- [ ] 長離與今汐的堆疊判定發生在回合結束後，而不是自己移動前。
- [ ] 初始同格團子的上下堆疊順序會隨 seed 亂序；固定 seed 重置後順序可重現。
- [ ] 即時名次以最接近終點到最遠排序，同格時依堆疊由上至下排序。
- [ ] 即時名次以表格顯示排名、團子名稱、對應棋子圖示、目前格數與狀態，棋子文字為團子名稱第一個字。
- [ ] 本輪行動以表格顯示行動順序、團子名稱、對應棋子圖示、本輪骰子與行動狀態。
- [ ] 即時名次欄位對齊為名次置中、團子靠左、格數靠右、狀態置中。
- [ ] 本輪行動欄位對齊為順序置中、團子靠左、骰子置中、狀態置中。
- [ ] 布大王在第 1、2 輪不顯示於本輪行動表格，第 3 輪開始若進入行動順序才顯示骰子。
- [ ] 事件紀錄位於單輪模擬工作區左側，團子與 Seed 設定集中在設定工作區。
- [ ] 中央賽道同格堆疊時，上方團子的棋子與文字都高於下方團子。
- [ ] 中央賽道裝置不會蓋住團子；目前行動團子會顯示高亮外框。
- [ ] 中央賽道會顯示中點標記，且預設資料的第 16 格會顯示中點。
- [ ] 初始狀態只有開始、參賽團子設定、速度、自動播放 checkbox、多輪模擬執行、場數、Seed、CPU worker、結果表 header 排序可操作。
- [ ] 單輪模擬開始後，下一步、自動播放 checkbox、暫停、重置可操作，開始、參賽團子設定與 Seed 設定不可操作；若多輪模擬尚未執行，多輪模擬執行按鈕、場數與 CPU worker 仍可操作。
- [ ] 點「下一步」後中央賽道、骰子、名次與事件紀錄會更新。
- [ ] 自動播放 checkbox 勾選後會自動播放，按暫停會取消勾選，重置會停止播放。
- [ ] 開始前可勾選自動播放 checkbox，按下開始後會直接自動播放。
- [ ] 單場比賽結束後，不需要按重置即可直接按「開始」開啟下一場。
- [ ] 重置後會回到初始控制狀態。
- [ ] 可執行批次模擬並看到勝率摘要。
- [ ] 多輪模擬進行中切換到其他工作區後再切回，進度、ETA 與停止按鈕狀態仍保留。
- [ ] 多輪模擬場數欄位可輸入到 99999999，欄位寬度可容納 `99,999,999` 等級文字。
- [ ] 多輪模擬場數欄位每次變更都會即時補上千分位逗號，不需等到失焦。
- [ ] 多輪模擬場數欄位在逗號旁按 Backspace/Delete 時，會刪除逗號左側/右側的數字，且游標不會多跳一格。
- [ ] Seed 輸入欄位旁顯示 `固定 Seed：` label。
- [ ] Seed 模式與固定 Seed 輸入欄位位於設定工作區，單輪模擬與多輪模擬共用此設定。
- [ ] Seed 模式選擇系統隨機 seed 時，Seed 輸入欄位不可編輯；切回固定 seed 後可編輯。
- [ ] CPU worker 選項包含自動、全力與 1 到目前 CPU core 數。
- [ ] CPU worker 自動模式使用約 2/3 CPU core，全力模式使用目前 CPU core 數。
- [ ] 載入較高核心電腦儲存的過大 CPU worker 數時，GUI 會回退到自動。
- [ ] 多輪模擬執行前會依場數試跑樣本場數，並以 Yes/No 對話框顯示正式 worker 數與預估時間，對話框內整數數字會使用千分位逗號。
- [ ] 多輪模擬預估對話框按 No 不會開始正式模擬；按 Yes 才會開始。
- [ ] 多輪模擬執行中會顯示完成場數、總場數與 ETA。
- [ ] 多輪模擬執行中場數、CPU worker 與執行按鈕不可操作，停止模擬可操作；若單輪模擬尚未執行，開始與自動播放 checkbox 仍可操作。
- [ ] 單輪模擬與多輪模擬可同時執行，切換到其他工作區後再切回，單輪畫面與多輪進度都會繼續更新或保留。
- [ ] 單輪模擬與多輪模擬同時執行時，參賽團子設定、Seed 模式與 Seed 輸入不可操作。
- [ ] 單輪模擬與多輪模擬同時執行時，多輪結果完成不會覆蓋正在進行的單輪 seed 顯示。
- [ ] 按下停止模擬後，多輪模擬控制會回到初始狀態。
- [ ] 固定 seed 連跑兩次同設定會得到相同批次結果。
- [ ] 系統隨機 seed 會在目前 seed 顯示區顯示本次實際使用 seed，但不回填覆寫固定 Seed 輸入欄位。
- [ ] 關閉並重新啟動 GUI 後，參賽團子、布大王模式、速度、單場自動播放、多輪場數、Seed 模式、Seed 輸入與 CPU worker 會恢復。
- [ ] 使用者設定檔損壞時 GUI 仍可啟動，並回到安全預設值。
- [ ] 批次結果表顯示勝場、勝率、平均名次與綜合分數。
- [ ] 批次結果表高度至少能顯示約 7 列結果，方便檢視 6 到 7 位參賽者。
- [ ] 批次結果表欄位對齊為排名置中、團子靠左、勝場/勝率/平均名次/綜合分數靠右。
- [ ] 批次結果表預設依綜合分數遞減排序，且 header 顯示 `綜合分數 ▼`。
- [ ] 批次結果表可點擊 header 在遞減、遞增、不使用此欄排序間切換。
- [ ] 批次結果表排名欄不可排序；升冪排序時排名欄依目前排序顯示 `N..1`。
- [ ] JSON 錯誤會顯示可理解訊息。

## CLI

- [ ] `dangosim simulate` 可讀取預設資料。
- [ ] `dangosim simulate --workers auto` 可完成多核心批次模擬。
- [ ] `dangosim simulate --workers full` 可完成多核心批次模擬。
- [ ] 預設資料可套用團子 builtin 技能並完成批次模擬。
- [ ] 預設資料內每個團子技能都有可供程式引用的 `id` 與可供 GUI 顯示的 `name`。
- [ ] 預設資料的 `track.devices` 可載入 `type: "midpoint"`，且中點標記不會取代同格裝置。
- [ ] 固定 seed 的輸出可重現。
- [ ] 同一固定 seed 使用 `--workers 1` 與 `--workers auto` 會產生相同統計結果。
- [ ] 系統隨機 seed 的 JSON/CSV 輸出包含本次實際使用 seed。
- [ ] 可輸出 JSON。
- [ ] 可輸出 CSV。
